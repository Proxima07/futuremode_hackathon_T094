# SnapFit v0.30：固定目標，讓構圖可以完成

這是接續 v0.29 的差異更新。ZIP 僅包含本次修改／新增檔案，保留原本目錄結構；
不是完整專案，也不包含 `.env`、金鑰、照片或前幾版 ZIP。

## 更新方式

1. 先備份自己的專案，再將 ZIP 解壓到專案根目錄，合併 `web/`、`server/` 等同名資料夾。
2. 前後端要一起更新。新前端會傳送 `phase`，新後端才懂「固定目標」契約。
3. 重新啟動原本的 Python／Uvicorn 服務，手機重新整理頁面。
4. `.env.example` 只是範例，**不要用它覆蓋自己的 `.env`**。`VLM_TEMPERATURE` 未設定時預設為 `0`；
   若自己的 `.env` 已設定其他值，可自行改為 `VLM_TEMPERATURE=0`。
5. 按 D 的除錯面板或瀏覽器 Console 應顯示 `v0.30`。不需要新增套件或前端 build。

## 本次行為

- 選擇構圖：同一版型與方向累積兩次才定案。若三次提案仍不一致，選多數；同票選最近提案。
  這只決定構圖目標，不代表已可拍攝。沒有辨識到主體時不累積候選。
- 固定目標：鎖住版型、鏡射、上下翻轉、平移、縮放、交點和對準部位。
  不會因為使用者靠近交點，就把交點再移走。手選版型會直接進入固定目標階段。
- 單一步驟：新方向連續兩次一致才替換提示；移除清單變動也要確認。
- 可以拍攝：鎖定後最近三次有效判斷有兩次 `ready`，才顯示「構圖完成，可以拍攝」和綠色快門外圈。
  主體消失會清空完成票；有明確干擾物或未辨識到主體時不接受 `ready`。
- 完成後不再持續提出美學微調，也暫停會要求變換機位的光線提示。
  但只完成構圖不代表已保證對焦／曝光，仍會提醒使用者確認清晰與亮度。
- READY 後以低成本縮圖監看畫面，持續明顯變化時撤銷完成狀態，沿用原目標重新確認。
  另約每 12 秒做一次語意複查（仍不重新設計版型），避免畫面相似卻已換主體而永久停在 READY。
- 原主體連續兩次消失／被更換才重新選方案。手選模式保留手選版型。
- 「重新分析」會清除舊目標與手動鎖定，讓 AI 重新選。換情境／鏡頭也重新分析。
  縮放和手機旋轉則保留目標、撤銷舊完成票後重驗。
- 快門不必等 READY，使用者隨時可以自行決定拍攝。

## Prompt 與後端改動

`PLAN_SYSTEM` 負責 SEARCHING 的版型選擇和一次性的初始調整。
新增較短的 `GUIDING_SYSTEM`：不再提供可選版型目錄，只送目前的固定座標、
`item`、`feature`、上一動作與提示，要求回傳 `move / ready / lost`。

提示詞明確允許「足夠好」：交點約容許畫面對角線 10% 偏差；對角線約容許
10 度角差與畫寬 7% 的偏移。這些是給模型的目視判斷指引，**不是已實作的像素級量測**。
保留餐點印刷墊紙、醬料杯、人像與環境等情境規則。

後端會強制 GUIDING 沿用目前版型並丟掉 `adjust/custom`，前端也不讓引導回應進入
幾何更新入口。`feature` 例如「杯標中心」一旦選定就沿用，不得下次換成「杯蓋」。
相機／情境／重新分析切換後，舊工作階段的慢回應會被丟棄。

模型溫度預設降為 0，可降低輸出變動，但不保證同一張照片每次回答完全相同。
候選票數、完成票數與提示穩定性由程式控制，不只依靠 Prompt。

## 驗證與限制

離線測試：26 項 JavaScript 測試、13 項 Python 測試。包含實際 main.js 處理流程的模擬，
以及版型／部位鎖定、READY 投票、動態版型、低頻複查、過期回應、重新分析與 provider 溫度契約。
沒有連到使用者的 Gemma 端點，未用真實手機鏡頭驗證辨識準確度，也沒有量測實際推論延遲。

可在專案根目錄重跑（Python 使用原本已裝好 requirements 的環境；Node 測試以 Node 24 驗證）：

```bash
node --test tests/*.test.mjs
python -m unittest discover -s tests -p 'test_*.py'
```

搜尋／引導階段現在即使畫面不動也會送後續影格，才能完成確認，因此該階段的呼叫量
可能高於舊版；READY 後才降低頻率。700ms 是收到回應後的等待間隔，不是保證 700ms 得出結論。
模型持續錯判、服務失效或畫面一直移動時，不會用逾時強制假裝 READY；仍可按快門或重新分析。

縮圖偵測不是人物／物件追蹤器，快速換主體、強烈動態背景、微小位移仍可能漏判或誤觸發。
這版解決的是目標漂移與決策反覆，不宣稱已取代專用的偵測、追蹤或對焦品質分析。
