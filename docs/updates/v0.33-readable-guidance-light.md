# v0.33：提示閱讀時間與主體補光判斷

## 調整內容

1. 明確的移動與移除提示至少保留 5 秒。模型與畫面掃描仍照原頻率在背景執行；停留時間只影響文字切換，不降低判斷速度。
2. 停留期間只保留最新一筆候選提示，不累積過時指令。主體消失、到達目標、畫面大幅改變、重新分析等狀態可立即打斷。
3. 新增本機主體亮度防線。每秒利用既有曝光統計檢查主體區域及主體／背景亮度比；連續兩次偏暗或背光才顯示補柔光提醒，恢復也需連續確認，降低自動曝光造成的閃爍。
4. 光線 VLM 仍只在首次分析或明確且持續的光線變化後呼叫。亮度變化判定加入主體區域差異，不會只看整張畫面平均值。
5. 光線 Prompt 明確要求先看主體紋理、商品細節、食物層次或人像臉部；「仍可辨認」不等於亮度足夠，有氛圍的環境也可以同時需要少量補光。
6. 構圖已完成但光線偏暗時，固定版型與目標不變，提示使用者補光後再拍；手動快門仍可使用。

## 可調參數

- `web/js/lib/config.js` → `GUIDANCE_HOLD_MS: 5000`：明確指示最短顯示時間。
- `LIGHT_READABILITY`：本機偏暗／背光門檻與連續確認次數。
- `LIGHT_CHANGE`：觸發遠端光線重判的變化幅度與最短間隔。
