# v0.34：修 v0.33 的定不下來，並把節奏交還給使用者

只包含本次修改／新增的檔案，保留原本目錄結構。
解壓到專案根目錄合併覆蓋，**後端有變動要重啟 uvicorn**。

---

## 一、v0.33 為什麼定不下來

`main.js` 的這一行：

```js
const lightReady = !!light && light.verdict !== "problem";
```

`!!light` 是關鍵。v0.32 起光線分析改成
「只在首次或明顯變化時才呼叫」，最短間隔 15 秒。

所以只要光線還沒回來、或回了 `fallback`，
`lightReady` 就是 `false`——**構圖明明對好了，
狀態列仍停在「構圖已到位・確認光線中」，快門永遠不變綠。**

配上狀態列一直寫「持續判斷中」，就是你看到的「定不下來」。

**修法：光線是輔助資訊，不是構圖完成的前提。**

```js
const lightBlocking = !!light && light.verdict === "problem";
const lightReady = !lightBlocking;
```

只有「明確判定有問題」才擋，未知一律視為可拍。
真的太暗時狀態列改成「構圖已到位・建議先補光」，
快門仍然可以按。

## 二、提示停留更久

| 參數 | v0.33 | v0.34 | 位置 |
| --- | --- | --- | --- |
| `GUIDANCE_HOLD_MS` | 5000 | **7000** | `web/js/lib/config.js` |
| `STABILITY.adviceRefreshMs` | 1000 | **2500** | 同上 |

前者是「明確指示至少顯示多久」。
使用者要讀完、抬頭、動手、再低頭確認，五秒偏短。

後者是「同方向提示最快多久換一次字」。
一秒太快，人還在照著上一句做，文字就換掉了，會覺得系統很躁。

**兩個都只影響文字切換的時機，不減慢背景判斷。**
主體消失、到達目標、畫面大幅改變仍然會立刻打斷。

嫌不夠久就把 `GUIDANCE_HOLD_MS` 再調大。

## 三、補光提醒更早出現

你回報「畫面有點黑，但它說可以拍了」。原因在門檻：

| 參數 | v0.33 | v0.34 |
| --- | --- | --- |
| `darkMean` | .20 | **.28** |
| `darkSubject` | .26 | **.34** |
| `backlitSubject` | .28 | **.36** |
| `backlitRatio` | .55 | **.62** |

`.20` 已經是相當暗的畫面，使用者早就覺得不行了，系統卻還沒反應。

同時在 `LIGHT_SYSTEM` 加了一段：

> **「勉強看得出來」不等於「亮度足夠」。**
> 判斷標準是拍出來能不能直接用——
> 商品的紋理材質、食物的層次光澤、人像的臉部。
> 只要有一項模糊就給 problem。
> **寧可多提醒一次，不要讓使用者拍出一張沒辦法用的照片。**

也明確允許「同時是風格、而且需要補一點光」，
這兩件事不衝突：

> 「氣氛很好，但主體太暗，從正面補一點柔光就好」

**代價：**在刻意的暗調場景可能偶爾誤報。
但漏報的後果是使用者拍出一張不能用的照片，比較嚴重。
覺得太吵就把 `LIGHT_READABILITY` 的門檻調回去。

## 四、縮放改成兩指手勢

固定的滑桿一直浮在畫面上，會擋住正在取景的區域，
而取景就是這個產品的全部。

新增 `web/js/ui/pinchZoom.js`：

- 兩指張開縮放，是相機 App 的通用手勢，不用教
- 只在縮放時淡入一個倍率標示，一秒後自動消失
- 桌機測試可用 `Ctrl + 滾輪`
- 倍率用相乘不是相加，任何起始倍率下手感一致
- 手勢一秒觸發上百次，只保留最新目標值依序套用，
  避免慢的舊請求後到把倍率倒退回去

原本的滑桿保留著，`.env` 設 `PINCH_ZOOM=false` 就會切回去。

---

## 五、介面開關移到 .env

新增 `GET /api/ui-config`，前端啟動時抓一次。
抓不到就用 `config.js` 的預設值，不會擋住相機啟動。

`.env` 可以設定：

```
# 「持續判斷中・回覆 2.3 秒前」那條狀態列
# Demo 時建議關掉，它會讓畫面看起來一直在忙
SHOW_ANALYSIS_STATUS=false

# 按 D 的除錯面板
ALLOW_DEBUG_PANEL=true

# 兩指手勢縮放（false 會退回畫面上的滑桿）
PINCH_ZOOM=true
```

改完重啟 uvicorn，前端重整就套用。
